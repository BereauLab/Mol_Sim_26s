# MD with NVT ensemble using Nose-Hoover thermostat

You have here a simple code to run a LJ system on the NVT ensemble using the Nose-Hoover thermostat with a single chain. 

The code allows you to run on NVE or NVT by activating or deactivating the thermostat. 

For the code to run, you also need the file `thermostats.py` which contains a basic implementation of velocity rescaling and Nose-Hoover thermostat.
